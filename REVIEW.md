# Technical review

Mooni Dark follows Omarchy's color-theme contract: `colors.toml` is canonical,
`shell.toml` covers the shell surfaces, and root-level `vscode-theme.json` and
`helix.toml` are color-only overrides accepted for Git-installed themes.

The editor generator also creates standalone integration copies and a Zed theme
using schema v0.2.0. Regression tests verify generated-file freshness, clone-name
independence, semantic mappings, UI selection states and WCAG contrast. The
minimum measured syntax contrast is 6.56:1 against the editor background.

The repository does not ship Lua, terminal launch configuration, `vscode.json`
or automatic editor reload hooks. Neovim and terminal files remain generated by
the installed Omarchy version. Real desktop and session-lock captures are used
for both GitHub and the Omarchy selector.
